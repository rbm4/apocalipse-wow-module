# Bladeguard

Status: Implemented in source and data; database, client, build, and runtime not verified

Owners: `src/mod_apocalipse_rogue_bladeguard.cpp`, `data/sql/db-world/2026_09_22_04_bladeguard.sql`, `data/sql/db-world/2026_09_25_01_bladeguard_threat.sql`, and `data/sql/db-world/2026_09_25_04_spell_proc_mask_cleanup.sql`

Last validated: 2026-09-25 by static review against local module and custom core sources

## Summary

Bladeguard is a shield-dependent Rogue tank passive. While its learned passive is active with a usable shield equipped, it increases armor from equipped items by 130 percent, adds 15 percentage points of block chance, increases threat generated by Rogue-family abilities by 75 percent, and restores 5 Energy after a successful block at most once per second.

## Scope

- Passive spell 901073 owns the shield requirement, armor modifier, block modifier, and proc trigger.
- Helper spell 901074 performs the fixed 5 Energy restoration.
- Hidden helper aura 901155 applies a native 75 percent `SPELLMOD_THREAT` modifier to the complete Rogue spell family.
- The module aura script applies and removes 901155 with the shield-gated parent aura.
- Acquisition is intentionally external to these migrations.
- Shield skill, shield proficiency, and Block capability remain owned by the default-skill path documented in [`../features/rogue-shield-proficiency.md`](../features/rogue-shield-proficiency.md).

## Mechanical contract

| Mechanic | Contract |
|---|---|
| Equipment gate | Item class Armor, shield subclass mask 64, shield inventory mask 16384 |
| Armor | `SPELL_AURA_MOD_BASE_RESISTANCE_PCT`, Physical mask 1, amount 130 |
| Block | `SPELL_AURA_MOD_BLOCK_PERCENT`, amount 15 |
| Proc events | Taken melee auto attacks and taken melee/ranged damage-class spells that resolve as a block |
| Proc result | Trigger 901074 on self for 5 Energy |
| Threat | Native `SPELL_AURA_ADD_PCT_MODIFIER` with `SPELLMOD_THREAT`, amount 75, Rogue family 8, and an empty family mask so every Rogue-family ability qualifies |
| Threat lifecycle | Aura script casts hidden non-saved helper 901155 when 901073 applies and removes it when 901073 leaves |
| Internal cooldown | Core-owned 1000 ms cooldown on passive 901073 |

The armor aura modifies `BASE_PCT` before Agility and flat armor additions in `Player::UpdateArmor()`. It therefore increases armor sourced from equipped items, not total final armor.

The threat modifier runs in `ThreatManager::CalculateModifiedThreat` before school modifiers. It applies to both native ability threat and scripted bonus contributions that preserve the originating Rogue spell, including Buckler Strike and Daring Challenge bonus threat. Their existing multipliers therefore compose multiplicatively with Bladeguard. Auto attacks pass no spell and remain unchanged.

## Equipment lifecycle

The implementation uses the core's item-dependent passive contract instead of a module hook:

```text
learned passive 901073 plus usable shield
  -> ApplyItemDependentAuras applies Bladeguard
  -> armor, block chance, and block proc become active
  -> aura script applies helper 901155
  -> core threat calculation multiplies Rogue-family ability threat by 1.75

shield unequipped, swapped away, or unusable
  -> RemoveItemDependentAurasAndCasts removes Bladeguard immediately
  -> aura script removes helper 901155
  -> all four bonuses stop together
```

A broken or unusable shield also fails the native proc equipment check. The spell does not teach Shield, grant proficiency, or enable the ability to block.

## Human and bot behavior

Humans and bot-controlled Rogues use identical aura, equipment, threat-modifier, block-resolution, and cooldown paths. Bladeguard does not call `WorldSession::IsBot()` and adds no playerbot strategy or gear-selection policy. Bot acquisition and choosing to equip a shield remain external.

## Data and deployment

The automatic world updates `2026_09_22_04_bladeguard.sql` and `2026_09_25_01_bladeguard_threat.sql` install guarded rows for spells 901073, 901074, and 901155, exact proc metadata, the parent script binding, non-save helper metadata, updated descriptions, and backend display names. The idempotent follow-up `2026_09_25_04_spell_proc_mask_cleanup.sql` clears the inapplicable spell phase mask from taken-event proc 901073 while preserving its block hit mask and one-second cooldown. All three IDs require matching deployed client spell data before the passive is exposed to clients.

The migration deliberately does not add `mod_spec_spells` or another acquisition row. Rollback must remove the proc and spell rows only after external grants are revoked. Live database collision checks, updater execution, worldserver startup, and deployed-client validation remain operator work.

## Invariants

1. Spell 901073 must remain passive and shield-dependent so equipment changes control all bonuses atomically.
2. The armor effect must remain base Physical resistance percentage, not total resistance percentage.
3. The block proc must require `PROC_HIT_BLOCK` and retain its 1000 ms cooldown.
4. Spell 901074 must restore exactly 5 Energy and must not acquire its own equipment requirement.
5. Helper 901155 must remain non-saved, Rogue-family scoped, and use an empty class mask so custom and stock Rogue-family abilities are both affected.
6. Helper 901155 must be removed whenever shield-gated parent aura 901073 is removed.
7. Bladeguard must not grant Block capability, Shield skill, or shield proficiency.

## Verification

| Scenario | Expected | Status |
|---|---|---|
| Learn Bladeguard without a shield | No Bladeguard aura or bonuses | Not run |
| Equip a usable shield | Aura appears; item armor increases by 130 percent and block chance by 15 points | Not run |
| Unequip the shield | Parent and threat-helper auras and all bonuses disappear immediately | Not run |
| Use stock and custom Rogue-family abilities with a shield | Each ability generates 75 percent more threat; auto attacks and non-Rogue-family spells are unchanged | Not run |
| Use Buckler Strike or Daring Challenge bonus threat with a shield | Existing bonus contribution is also multiplied by 1.75 because it retains the originating Rogue spell | Not run |
| Block repeatedly inside one second | Only the first successful block restores 5 Energy | Not run |
| Block again after one second | Restores another 5 Energy | Not run |
| Human and bot Rogue | Identical mechanics when learned and shield-equipped | Not run |
