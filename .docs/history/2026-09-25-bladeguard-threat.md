# 2026-09-25: Bladeguard Rogue-family threat

Status: Partial

## Intent

Extend Bladeguard so its shield-equipped tank stance generates 75 percent more threat from every Rogue-family ability without increasing auto-attack or unrelated spell threat.

## Scope

### Code and data

- `src/mod_apocalipse_rogue_bladeguard.cpp`: couples the hidden threat helper to the shield-gated parent aura lifecycle.
- `src/mod_apocalipse_loader.cpp`: registers the Bladeguard aura script.
- `data/sql/db-world/2026_09_25_01_bladeguard_threat.sql`: adds guarded helper 901155, parent binding, non-save metadata, descriptions, and backend name.

### Documentation

- Updated the Bladeguard owner page, architecture, runtime flow, operations, playerbot integration, root README, allocation range, and history index.

## Contracts changed

- Hooks or registration: Added an AuraScript apply and remove lifecycle binding on Bladeguard 901073.
- Human behavior: While Bladeguard is active with a usable shield, threat generated by all Rogue-family abilities is multiplied by 1.75.
- Bot behavior: Identical to humans when the bot has Bladeguard and a usable shield.
- Configuration: None.
- Database or migration: Adds automatic world update `2026_09_25_01_bladeguard_threat.sql` and reserves spell 901155.
- Custom spell/client data: Adds hidden non-saved Rogue-family spell modifier 901155 with `SPELLMOD_THREAT`, amount 75, and an empty family mask.
- Deployment or rollback: Requires updater execution, matching client data, a rebuilt module, and a worldserver restart. Rollback must remove acquisition before removing owned spell and binding rows.

## Decisions

- Used native `SPELL_AURA_ADD_PCT_MODIFIER` rather than school-wide `SPELL_AURA_MOD_THREAT` so auto attacks and unrelated spell families remain unchanged.
- Used an empty spell-class mask with Rogue family 8 so stock and custom Rogue-family abilities qualify even when a custom spell has no family flags.
- Added a helper aura because all three effect slots on parent 901073 already own armor, block chance, and block Energy.
